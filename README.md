# Colour Clock · 色彩时钟

时间不只显示出来，它还有颜色。整屏的颜色由当前时间算出来，一秒一变。

## 它是什么

打开应用，屏幕上只有大字时间，背景是一种颜色。这个颜色不是随机挑的，也不是几个主题来回切——它是把时钟直接翻译成十六进制颜色：

| 颜色的位置 | 由什么决定 |
| --- | --- |
| 第 1–2 位 | 小时，以及这一小时走了多少 |
| 第 3–4 位 | 分钟，以及这一分钟走了多少 |
| 第 5–6 位 | 秒，以及这一秒走了多少 |

所以午夜 `00:00:00` 是纯黑，越接近深夜越亮，`23:59:59` 接近纯白；一秒之内颜色还会再变 16 次左右。想知道此刻到底是什么颜色，点一下大字或下方胶囊，时间就切换成 `#rrggbb` 写法。

### 两种变色方式

表头最左边的 `☰` 是菜单，里面可以切换两种取色方式：

- **Colour Clock**：就是上面这张表，颜色直接由时分秒算出来，也是应用的默认；
- **Jack Hughes**：颜色沿一个色环匀速走完一圈，一圈的长短自己定（菜单里的 PERIOD 滑杆，1 分钟到 24 小时，默认 60 分钟）。这个模式下 TIME / COLOUR 两个胶囊会收掉，因为已经没有「颜色代码」可看了，屏幕上只剩大字时间。

色环跟着墙上时间走：每一圈的起点都对齐整点，所以中途杀掉应用再打开，颜色不会跳走；几台设备同时打开，也一直是同一个颜色。

## 怎么用

界面只有五个可以点的地方，其余都不用管：

- **左上 `☰`**：菜单，切换上面两种取色方式，并设置 Jack Hughes 一圈的时长；
- **大字时间**：点一下在「时间」和「颜色代码」之间切换；
- **下方 TIME / COLOUR 两个胶囊**：效果和点大字一样，只是位置更好按；
- **右上角 `A`**：字号滑杆。时间字的大小可以调到 40%–160%，松手就记住，下次打开还是这个大小；
- **右上角 `i`**：关于本应用，写明它的离线与隐私承诺。

横屏竖屏都自适应，跟随系统的自动旋转开关。启动就是全屏，状态栏和导航栏都不占地方。

## 隐私

这一条是本应用的核心，不是装饰：

- **完全不联网**。APK 里没有申请任何权限，装好后在「应用信息 → 权限」里能看到的是「无权限」；
- 不采集、不存储、不传输任何个人信息或设备数据，没有账号、没有广告、没有推送、没有统计；
- 没有嵌入任何第三方 SDK，界面和取色逻辑全部自己实现；
- 时间跟随设备时钟和时区（含夏令时），除此之外不读取任何东西。

## 安装

1. 打开本仓库的 [Releases](https://github.com/Shiraha-cloud/the-colour-clock/releases)，下载 `colour-clock-1.2.0-release.apk`（约 71 KB）；
2. 传到手机上点开安装。因为不在应用商店里，系统会提示「未知来源 / 不受信任的应用」，确认是这个文件后允许即可；
3. 支持 Android 4.0 一直到 Android 16，不需要 Google Play 服务，手机平板都能装。

> 目前的 APK 用调试密钥签名。以后换成正式签名时，老版本没法直接覆盖升级，需要先卸载再装新版。

## 常见问题

**为什么颜色是固定的，不能自己选？**
颜色就是时间本身，选色会破坏这个对应关系。想看清它到底是什么颜色，切到 COLOUR 读数就行。

**Jack Hughes 模式的颜色是怎么来的？**
不再从时间里取十六进制，而是画一个色环：亮度固定，饱和度顶到屏幕能显示的边界，再按你选的周期匀速走完一圈。选 24 小时就是一天回到起点，选 1 分钟则一分钟走完。颜色一直在动，但每一步的差别都很小，看不出闪烁。

**菜单里 PERIOD 滑杆怎么是淡的？**
Colour Clock 模式下它不影响颜色，所以画得很淡以免让人以为在生效。直接拖它也行，一按下去就自动切到 Jack Hughes。

**手机倒过来拿，画面为什么不跟着转？**
这一版改了。以前反向竖屏（转 180°）不翻转，是因为系统那个旋转档位本身就不含它；从 Android 4.3 起四个方向都会转，倒过来拿也转。4.0 到 4.2 的系统没有这个档位，仍然只有三个方向。

**竖屏里字号怎么放大一点点就停了？**
这是有意的：宁可停止放大，也不让数字被屏幕边缘切掉。竖屏默认字号已经几乎占满宽度，所以往上只有约 6% 的空间，往下可以缩到 40%；横屏宽度富余，可以放大到约 1.6 倍。

**会不会很耗电？**
只在颜色或时间数值真的变化时才重绘一次，动画一结束就停；没有后台服务，不会唤醒手机，息屏后立刻停止工作。整个应用不到 70 KB，也没有任何第三方库。

**状态栏被隐藏了，会不会影响其他应用？**
不会，只在本应用里隐藏，退出即恢复。刘海和系统栏占用的安全区只用来避让文字内容，颜色仍然铺满四个角。

**为什么没有 12 小时制？**
颜色算法用的就是 0–23 的小时数，加一个 12 小时制的显示开关只会让「看到的时刻」和「算出的颜色」对不上，所以没做。

**深色模式？**
跟随系统的夜间主题：背景转黑，文字颜色自动保持可读。

## 想自己编译

源码只有 4 个 Java 文件，全部用 Android 框架自带的 API，没有 AndroidX、没有 Kotlin、没有 WebView：

- `MainActivity.java`：窗口、全屏、旋转、安全区；
- `ClockView.java`：唯一的视图，界面和交互都在一块画布上手绘；
- `ColourEngine.java`：时间 → 颜色的换算（Colour Clock）；
- `ColourLoop.java`：色环本身，以及它在某个周期里走到哪一步（Jack Hughes）。

用 Android Studio 直接打开本目录即可（AGP 8.13.2），命令行：

```bash
export JAVA_HOME="/path/to/jdk-17"
export ANDROID_HOME="/path/to/android-sdk"
gradle --no-daemon assembleDebug assembleRelease testDebugUnitTest
```

产物在 `app/build/outputs/apk/`。仓库自带 25 条测试，不需要真机：18 条离屏渲染（Robolectric）验证颜色铺边、字号不裁切、菜单与中文断行这些几何细节，7 条核对色环本身走得对不对。
